# 拾影 ClipHarbor 手機版

Personal iPhone video downloader. Docker service for Render Free and a private Sites frontend.

Paste a supported public video URL, wait for conversion, then preview and save the MP4. Requires a private ACCESS_CODE environment variable (at least 16 characters). Never commit account credentials or private cookies.

Free hosting has sleep, traffic, storage and platform limitations. The service limits video duration to 20 minutes and expires temporary media after 30 minutes. Download only content you are authorized to save.
